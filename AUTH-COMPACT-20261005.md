# LiDAR-Knight Auth 4.4.29

DeAndre's current appearance choice is opaque black, replacing the previous transparent window. The default Windows size is 550 × 420 with a one-time saved-size migration; later user resizing is preserved. Inter text and solid off-white labels replace dotted body text. Sparse native Flutter point-cloud, corridor and mist effects provide the red LiDAR scene without an embedded browser or Three.js dependency.

The home screen separates LIDAR ADMIN from the ordinary AUTHENTICATOR. An individual four-field owner ENV can be imported locally into the encrypted offline vault. Provider ENV files, unknown fields, oversized files and inconsistent OTP parameters are refused. Managed credentials are excluded from normal synchronization and export. Their identity cannot be silently changed, deleted or imported through ordinary account flows.

Admin codes are hidden until clicked, float above the mist, and hide immediately on focus loss, credential change, or after 15 seconds. Copied codes are cleared on hiding only if the clipboard still contains this app's last copied code; unrelated clipboard contents are preserved.

Replacement of an existing managed key fails closed unless a fresh production code-only sign-in proves the same seat, admin capability, enrolled credential and an increasing safe generation. ENV contents never leave the app. The temporary proof session is signed out and discarded. The currently older public game server does not expose this metadata, so replacement is not yet usable there.

Different-admin reset is prepared separately against game source 7ad6bdf28e260bde921187f69f8e698da058b780 under six-messageboard/owner-access-staging/admin-reset-20261005-7ad6bdf-recovery-v2. It is not integrated or deployed. It requires a different current human admin and a separate valid inviter plus configured fresh enrollment before revoking the target. Old ENV uploads cannot restore a revoked seat. DESIGN still owns terminal UI and fresh human replacement-key delivery. Do not include this server patch in an Auth-only download release.

Validation: 22 focused Flutter tests pass; focused static analysis is clean. These include synthetic ENV/policy/replacement-metadata checks, masking/clipboard behavior, compact layout, contrast and startup failure handling. They are not native owner enrollment, real server sign-in, reset, email or gameplay acceptance. Native build/install/public verification is recorded separately in the coordination evidence directory.

Existing owner data, the original Lidar4K.prproj and supplied emblem are preserved. Windows is the installer being built and checked; other native platforms require their own builds and acceptance. No owner key, OTP, provider secret or authenticator profile belongs in source/media/release archives.
